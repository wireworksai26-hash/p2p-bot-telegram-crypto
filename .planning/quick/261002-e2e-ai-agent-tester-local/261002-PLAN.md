# Quick Plan 261002 — Autonomous E2E AI Agent Tester for Telegram Bot (Local Only)

**Goal:** Membangun sistem pengetesan End-to-End (E2E) otomatis menggunakan AI Agent untuk bot Telegram P2P Crypto secara komprehensif, aman, dan terisolasi khusus di lokal (tidak di-push ke remote).

**Mode:** quick (Local Only)
**Output Directory:** `local_e2e_agent/` (Protected by `.gitignore`)

---

## Task Breakdown

### Task 1: Local Environment Setup & Git Protection
- **Files:** `.gitignore`, `local_e2e_agent/config.py`, `local_e2e_agent/reporter.py`
- **Actions:**
  1. Daftarkan `local_e2e_agent/`, `*.session`, `*.session-journal`, `local_reports/` ke dalam `.gitignore` untuk menjamin 100% isolasi lokal.
  2. Buat `local_e2e_agent/config.py` untuk mengelola konfigurasi tester (target bot username, timeout, skenario aktif).
  3. Buat `local_e2e_agent/reporter.py` untuk menghasilkan ringkasan eksekutif dan tabel status uji (Pass/Fail/Latency) yang siap diserahkan ke owner.

### Task 2: Mode 1 — Headless Autonomous E2E Flow Simulator
- **File:** `local_e2e_agent/headless_agent.py`
- **Actions:**
  1. Bangun harness simulasi async python-telegram-bot untuk menguji 7 skenario lengkap:
     - **Skenario 1: Dashboard Utama & Greeting** (`/start`, statistik user & bot).
     - **Skenario 2: Beli Crypto (Buy Flow)** (USDT BSC $\rightarrow$ QRIS generation $\rightarrow$ payment simulation $\rightarrow$ auto crypto payout).
     - **Skenario 3: Jual Crypto (Sell Flow)** (ETH BASE $\rightarrow$ deposit address $\rightarrow$ on-chain deposit simulation $\rightarrow$ admin payout with proof photo upload).
     - **Skenario 4: Convert/Swap Crypto** (USDT BSC $\rightarrow$ ETH BASE $\rightarrow$ deposit $\rightarrow$ auto-payout target coin).
     - **Skenario 5: Topup Saldo IDR** (QRIS $\rightarrow$ unique code $\rightarrow$ credit user balance).
     - **Skenario 6: Realtime Market Price & Hot Wallets Audit** (Cek harga murni + 30 cadangan wallet on-chain).
     - **Skenario 7: Executive Admin Control Center** (`/admin`, statistik, pending orders, wallets, audit trail log, user management, spread settings).
  2. Sertakan validasi assertion ketat pada setiap step: transisi status order, pembuatan hash transaksi, dan isolasi saldo.

### Task 3: Mode 2 — Real Telegram Userbot Client Agent (Telethon)
- **File:** `local_e2e_agent/telegram_userbot_agent.py`
- **Actions:**
  1. Bangun client agent berbasis Telethon untuk live testing di aplikasi Telegram nyata.
  2. Implementasikan helper interaksi:
     - `send_command(cmd)`
     - `click_inline_button(text_pattern)`
     - `send_photo_proof(image_path)`
     - `wait_for_bot_response(expected_keywords, timeout=15)`
  3. Evaluator AI Agent: Menganalisa kualitas pesan balasan bot, kecepatan respons, dan menangkap anomali/error traceback.

### Task 4: Unified CLI Runner & Verification
- **File:** `local_e2e_agent/run_agent.py`
- **Actions:**
  1. Buat interactive entry point CLI (`python local_e2e_agent/run_agent.py`) dengan menu pilihan mode yang elegan.
  2. Jalankan Mode 1 Headless Simulator untuk memvalidasi seluruh 7 skenario E2E di lokal.
  3. Generate file laporan hasil audit E2E di `local_e2e_agent/reports/`.
