# Quick Plan 261001 — Fix Bot Crash /Start Failure from Railway PostgreSQL Hostname Resolution Error

**Context:** User melaporkan bot Telegram tidak merespons `/start` berdasarkan log `error/logs.1790859973757.log`.
**Root Cause:** `DATABASE_URL` di environment Railway mengarah ke `postgres.railway.internal` yang gagal di-resolve oleh DNS container (`OperationalError: could not translate host name "postgres.railway.internal" to address`). Akibatnya `main.py` crash saat `init_database()`, PM2 masuk crash loop, dan polling Telegram bot tidak pernah start.

---

## Task List

### Task 1: Resilient Database Engine & Graceful SQLite Fallback
- **File:** `database/connection.py`
- **Action:**
  1. Bungkus inisialisasi SQLAlchemy engine dengan logic `create_resilient_engine()`.
  2. Lakukan pre-flight ping test (`SELECT 1`). Jika PostgreSQL gagal (DNS failure / host unreachable / auth error), tangkap `OperationalError` dan lakukan graceful fallback otomatis ke SQLite lokal (`sqlite:///./p2p_bot.db`) dengan `PRAGMA journal_mode=WAL` dan `busy_timeout=30000`.
  3. Pastikan `SessionLocal` dan `engine` tetap terdefinisi valid sehingga bot dapat terus berjalan tanpa crash.

### Task 2: Robust Database Migration & Startup Init
- **File:** `main.py`
- **Action:**
  1. Perbarui `init_database()` agar jika terjadi error tak terduga pada engine aktif, otomatis me-rebind engine ke SQLite fallback, menjalankan migrasi skema tabel, dan melanjutkan proses startup.
  2. Pastikan `build_bot_application()` dan polling bot dapat dieksekusi dengan mulus.

### Task 3: Hardening Database Session di GoPay Gateway
- **File:** `gopay-gateway/dbSession.js`
- **Action:**
  1. Pastikan error `getaddrinfo ENOTFOUND` pada PostgreSQL tidak mengganggu lifecycle startup Node.js gateway.
  2. Tetap andalkan sesi file `.GOPAY_SESI_JANGAN_DIHAPUS.json` sebagai fallback utama jika database eksternal unreachable.

### Task 4: Unit Test & Verification
- **Action:**
  1. Buat test script untuk memverifikasi perilaku fallback otomatis saat `DATABASE_URL` di-set ke host dummy/invalid (misal: `postgresql://user:pass@invalid.internal:5432/db`).
  2. Pastikan bot tetap startup dan engine fallback ke SQLite dengan sukses.
  3. Jalankan regression test suite.
